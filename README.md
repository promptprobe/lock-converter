# lock-converter

엑셀에서 복사한 표를 붙여넣고 여러 시트를 하나의 `.xlsx` 파일로 저장하는 단일 HTML 도구입니다.

## 바로 사용하기

- 웹에서 실행: <https://promptprobe.github.io/lock-converter/>
- HTML 다운로드: 웹페이지 오른쪽 위의 `HTML 다운로드` 버튼

다운로드한 `index.html`은 별도 설치나 서버 없이 브라우저에서 바로 열 수 있습니다. 엑셀 변환 라이브러리가 파일 안에 포함되어 있으므로 다른 파일은 필요하지 않습니다.

## 사용법

1. 엑셀에서 필요한 셀 범위를 복사합니다.
2. 웹페이지의 `엑셀 데이터` 입력창에 붙여넣습니다.
3. 미리보기를 확인하고 `시트 추가`를 누릅니다.
4. `엑셀 다운로드`를 눌러 파일을 저장합니다.

데이터는 별도의 서버로 업로드하지 않고 브라우저 안에서 처리됩니다. 새로고침하면 현재 작업 내용이 사라집니다.
